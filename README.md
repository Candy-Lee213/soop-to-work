# 숲으로 출근

모리걸과 세미 정장, 그 사이의 한 벌을 매일 제안하고, 입은 옷을 사진 달력에 남기는 개인용 웹앱.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 (화면, 동작, 저장) |
| `manifest.webmanifest` | 홈 화면에 설치할 때 쓰는 이름과 아이콘 |
| `sw.js` | 오프라인에서도 열리게 앱 파일을 보관. 인터넷이 되면 항상 새 파일을 먼저 받음 |
| `icons/` | 잎 단추 아이콘 (홈 화면, 브라우저 탭) |
| `leaf.jpg`, `clay.jpg` | 앱 안의 단추 이미지 |

## 데이터

- 핀, 기록, 사진은 이 저장소가 아니라 **사용하는 휴대폰의 브라우저 저장소(IndexedDB)** 에만 저장된다.
- 브라우저 데이터를 지우거나 휴대폰을 바꾸면 사라지므로, 앱의 **내 서랍 → 백업 파일 내려받기** 로 가끔 백업한다.
- 다른 기기로 옮길 때는 그 기기에서 **백업 파일 불러오기** 를 쓴다.

## 누끼

기록 사진을 올리면 브라우저 안에서 배경을 지워 사진 달력에 인물만 올린다 (`@imgly/background-removal`).
처음 한 번은 모델 파일을 내려받느라 시간이 걸리고, 이후에는 브라우저가 보관한 것을 쓴다.

## GitHub Pages로 올리기

1. 이 폴더의 파일을 저장소의 맨 위에 그대로 올린다 (`icons` 폴더 포함).
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장한다.
3. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 에서 열린다.

## 홈 화면에 설치 (아이폰)

Safari로 주소를 연다 → 공유 버튼 → **홈 화면에 추가**.
